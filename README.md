# EU AI Act & GDPR Compliance Guide

A comprehensive guide to understanding the EU AI Act and its intersection with GDPR compliance for startups and SMEs.

## Features

- Interactive compliance checker
- Detailed risk level classifications
- Sector-specific guidance
- GDPR-AI Act comparison
- Implementation timeline
- SME support resources

## Technologies

- Pure HTML, CSS, and JavaScript
- No build process required
- Responsive design
- Dark mode support

## Local Development

Simply open `index.html` in your browser or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server
```

Then visit `http://localhost:8000`

## Deployment

This site is deployed to GitHub Pages. The deployment happens automatically when you push to the `main` branch.
